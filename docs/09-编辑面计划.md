# 09 · 编辑面计划：让你自己改，不用等我

> 状态：**待你拍板，未动代码**
> 起因：你反复要「能自己编辑」，我一直用「我帮你改一次代码」代替了它。
> 分隔线冒 END、刊头卡封面占位图 —— 每次都改对了，但你的能力没增加。
> 这份计划只做一件事：**把编辑能力交到你手上**。

---

## 一、现状：你现在能改什么，改不了什么

| 层 | 你能改吗 | 通过什么 |
| -- | -- | -- |
| 颜色（7 个主色系 token） | ✅ | 配色面板 |
| 文案 / 字段增删（如删掉 `cover:`） | ✅ | 中间那栏 Markdown |
| **间距 / 字号 / 行距 / 字距 / 对齐** | ❌ | 锁在主题 JSON 的 `base` 里 |
| **组件结构（刊头卡有没有封面、卡片有没有边框、阴影、渐变）** | ❌ | 锁在主题 JSON 的 `components.*.tpl` 一整段 HTML 里 |
| 占位图配色 | ❌ | 引擎常量，写死 blue |
| 组件模板里的圆角 / 阴影细节 | ❌ | 同上 |

**真正的阻塞点**：一个组件的模板是「一整段 HTML 字符串」，结构 + 间距 + 配色三件事糊在一起，
只能整体替换、不能拆开逐项点。所以编辑面必须直接对这段字符串开刀（Step 2），
或者先把它拆开（Step 3，代价大）。

---

## 二、计划：三步，每步独立可用

### Step 1 · 尺度面板（约 1.5 小时）

把配色面板覆盖不到的 8+1 个尺度 token 也做成控件 —— 它们在 `theme.base` 里，
和颜色 token 一样是扁平键值，**复用现成的 overrides 机制即可，不动引擎**。

| 控件 | 键 | 默认（blue / mist） |
| -- | -- | -- |
| 正文字号 | `fontSize` | 15px / 16px |
| 章节标题字号 | `fontSizeTitle` | 22px / 23px |
| 行高 | `lineHeight` | 1.95 / 1.9 |
| 字距 | `letterSpacing` | 0 / 0.5px |
| 段间距 | `paraGap` | 20px / 22px |
| 章节上留白 | `chapterGap` | 40px / 46px |
| 卡片间距 | `cardGap` | 24px / 30px |
| 列表项间距 | `itemGap` | 12px / 12px |
| 对齐 | `align` | justify（**只能 justify / center** —— 微信禁 left/start/end，会告警） |

- 改动进 `overrides` → `currentTheme()` 里同时应用到 `t.base`（现在只应用到 `t.tokens`）
- 实时预览、导出固化，和配色面板完全同一条链路

### Step 2 · 组件模板编辑器（约半天）★ 核心

点顶栏新增的「模板」按钮 → **右侧抽屉（约 40% 宽，左侧预览仍然可见）**。
配色面板是全屏弹层，模板不能这么做 —— 改 HTML 时必须盯着预览看。

抽屉里四块：

1. **组件列表**：15 个组件，显示中文名（`MODULES[role].ui.label`）+ 一句说明。
2. **编辑区**：`textarea` 显示该组件的 `tpl`；有子模板的（highlights / compare / list）
   用分段 tab 切换「外层 / 每项 / 有序项」。
3. **变量面板**：自动列出本主题所有可用 `{{token}}`（tokens + base）+ 该 role 的 IR 字段
   （title / lede / cover / account / caption …），点一下插入到光标处。
4. **校验条**（最关键，防止改坏）：
   - 输出里残留 `{{` → 红字指出哪一段（复用现成的 `metrics.templateResidue`，
     **不重写 lint 规则** —— lint 只在 `check/lint_templates.py` 里实现一次）
   - 微信红线常驻提示：禁 `div / script / style / class / id / position / float`；
     文本必须包 `<span leaf="">`
   - 体检 chips（叶节点 / 污染 / 渐变 / 对齐）实时刷新

**一键手术**（下拉，每个都能撤销 —— 降低"我得读懂 HTML"的门槛）：

| 手术 | 做什么 |
| -- | -- |
| 删掉刊头卡封面 | 删 `{{?cover}}…{{/cover}}` 整段（就是你这次要的那个） |
| 去掉全部阴影 | 正则清掉 `box-shadow:...;` |
| 去掉全部圆角 | 正则清掉 `border-radius:...;` |
| 去掉全部渐变 | 正则把 `background:linear-gradient(...)` 换成纯色 |
| 恢复默认 | 清掉该组件的 override |

**存 / 导出**：完全复用现在的导出逻辑 —— 全量快照 `.js`、注册进 `GZH_THEMES`、
写 localStorage、`derivedFrom` 标注「改过模板」。给别人时对方用「导入主题」打开即可。

### Step 2.5 · 新增 / 删除组件（你问的那个）★ 半步，依附 Step 2

**为什么现在不能**：组件有两半 ——
「骨架」在 `engine/modules.js`（这个盒子怎么取值：整段正文？`key: value` 字段？一行一条列表？），
「皮肤」在主题 JSON（长什么样）。主题里**只有皮肤没有骨架**，
所以你只能在已有的 15 个骨架里挑，造不出新的。

**新增组件**（左栏一个「＋ 新建组件」按钮，四步）：

1. 起名字：中文名（左栏显示的）+ 语法名（`:::xxx` 里的 xxx）
2. 选「内容怎么取」：整段正文 / `key: value` 字段行 / 一行一条列表 ——
   三选一，覆盖绝大多数盒子
3. 从哪个现有组件复制模板当起点（不给空白，给个能跑的骨架）
4. 用 Step 2 的模板编辑器改成你要的样子

**技术上怎么落地（不动 IR 层的铁律）**：
主题 JSON 多一个可选字段 `modules`，装自定义组件的「骨架」（grammar + ui 信息）；
App 切主题时把它并进 `GZH.MODULES`，`ir.js` 一行都不用改；
导出时全量带走 —— 别人导入你的主题，这个组件跟着一起到。

**删除组件 —— 先分清你说的「删」是哪一种**：

| 你想的 | 实际做法 | 代价 |
| -- | -- | -- |
| 这篇稿子不用它 | 不用删。不写就不会出现（盒子写在哪渲染在哪） | 0 |
| 左栏不想看到它 | 隐藏开关，存 localStorage | 很小 |
| 这套主题彻底不要它 | 删掉它的模板 → 渲染自动回落到兜底模板，**不会崩也不会留白** | 小，但要提示「已回落」 |

**限制（先说清楚）**：

- 自定义组件**跨主题不通用**：主题 A 里造的，主题 B 没有它的模板 → 回落兜底。
  想通用就得上 Step 3 的 preset 层。
- 取值规则只给三种（正文 / 字段 / 列表）。更花的结构（多列对比那种 `item` + `subitem`）
  要么复制现有组件改，要么手写 grammar。
- 微信红线照旧，体检区实时拦。

### Step 3 · 元素化（可选，终局，1–2 天）

把模板拆成「元素（只有自身样式、不含外边距）+ 组合（顺序 + 间距）+ 主题（上色）」三层，
界面上逐项点属性，存成 preset 跨主题复用。

**只有当你觉得 Step 2「还是得读 HTML」太难时才做。**
代价：动引擎 + 3 套主题的 15 个组件模板全部重写，有返工风险。

---

## 三、风险与对策

| 风险 | 对策 |
| -- | -- |
| 模板改坏，输出满屏 `{{?x}}` | 残留检测实时红字 + 「恢复默认」一键回退 |
| 改出微信不合规的结构 | 体检 chips 实时报警 + 面板常驻红线清单 |
| 抽屉挡住预览 | 抽屉放右侧、40% 宽，预览区始终可见 |
| file:// 不能 fetch / 不能 ES Module | 全部走 localStorage + Blob 下载，与现有导入导出一致 |
| 原主题升级后改动冲突 | 导出的是**全量快照**，不依赖原主题还在（与现有一致） |

---

## 四、明确不做

- 拖拽式自由排版 —— 微信禁 `position` / `float`，拖了也白搭
- 云端 / 多人协作
- 占位图按主题配色重新生成 —— 另开一件（P1）

## 五、验收标准（怎么算做完了）

1. 删掉刊头卡的封面图
2. 把卡片间距从 30px 改成 20px

4. 造一个自己的组件（比如 `:::verdict` 结论卡），并在稿子里用它
