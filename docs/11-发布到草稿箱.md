# 11 · 发布到公众号草稿箱

> 把渲染好的正文，通过微信官方接口直接写进公众号后台的**草稿箱**，
> 不用再手动复制粘贴。

---

## 一、为什么要多跑一个本地代理（先看这个）

**浏览器不能直连微信 API。** `api.weixin.qq.com` 不返回 `Access-Control-Allow-Origin`，
页面里 `fetch()` 它会被 CORS 拦掉 —— 而本项目是 `file://` 打开的（origin 为 `null`），更严格。
所以请求必须先经过本机这个零依赖代理，由它补上 CORS 头再转发。

`tools/wechat-proxy.js` 刻意做得很少：

| 约束 | 做法 |
| -- | -- |
| 不存密钥 | AppID / AppSecret 只在请求经过时出现在内存里 |
| 不落日志 | 一个字都不写盘 |
| 不对外 | 只监听 `127.0.0.1`，局域网其它机器连不上 |
| 不当中转跳板 | 只能转发到 `api.weixin.qq.com`（写死白名单，挡 SSRF） |
| 不扛大包 | body 上限 20MB；路径只认 `[a-z0-9_-/]` |

**不发稿的时候可以关掉（Ctrl+C）。** 它只在你要发稿的那几分钟需要开着。

---

## 二、三步跑起来

### 1. 起代理

```bash
node tools/wechat-proxy.js          # 默认 8787；想换端口：node tools/wechat-proxy.js 8899
```

看到「微信 API 本地代理已启动」就行。端口被占用时会直接告诉你，不会静默失败。

### 2. 把本机公网 IP 加进白名单

App 顶栏点「**发布到草稿箱**」→ 点「**查 IP**」→ 复制那个 IP →
去公众号后台 **设置与开发 › 基本配置 › IP白名单** 添加，**保存后等 1 分钟**再回来。

> 微信校验的是**调用方的公网出口 IP**。家用宽带每次拨号都可能变，
> IP 变了就要重新加白名单 —— 所以面板里那个「查 IP」按钮是常驻的，不是一次性的。
> 忘了这一步的表现是 `errcode 40164: invalid ip`。

### 3. 填密钥 → 测试 → 发送

| 字段 | 说明 |
| -- | -- |
| AppID / AppSecret | 公众号后台「设置与开发 › 基本配置」。**只存在本机浏览器 localStorage，不写进导出主题、不外传** |
| 作者 | 留空则取稿子里 `:::profile` 的 `author` |
| 原文链接 | 可选，文末「阅读原文」 |
| 摘要 | 可选，留空微信自动截取 |
| 封面 media_id | **草稿接口必填**，必须是素材库里的**永久图片**素材 |
| 正文图片 | 正文里的图要先传进公众号才能显示，详见第四节 |

封面有两种拿法：

- **上传一张** → 走 `material/add_material`，上传完自动填 media_id
- **从素材库选** → 拉最近 20 张图片素材，点一下就选中

然后「**测试连接**」（拿 access_token）→「**发送到草稿箱**」。

---

## 三、三个前提，缺一不可

1. 公众号是**已认证**的服务号/订阅号 —— 未认证号没有草稿接口权限（表现：`48001`）
2. 本机公网 IP 已在白名单里（表现：`40164`）
3. AppID / AppSecret 填对（表现：`40013` / `40125`）

常见 errcode 面板里已经翻成中文，主要几个：

| errcode | 含义 |
| -- | -- |
| 40164 | IP 不在白名单 |
| 40001 | access_token 无效/过期，重新「测试连接」 |
| 40013 / 40125 | AppID / AppSecret 不对 |
| 48001 | API 未授权（多为未认证号） |
| 40007 | media_id 无效（封面不是永久素材） |
| 45009 | 超过接口调用限额 |

## 四、正文图片：上传并替换（必须做的一步）

微信草稿正文只认自己域下的图片地址（`mmbiz.qpic.cn`）。占位图是 base64 `data:` URI，
外链图也不保证显示 —— 所以**正文里的图必须先传进公众号**，拿到微信的 URL 再替换掉。

面板里那一行「**正文图片**」会实时显示：`共 N 张 · 已上传 M · 待上传 K`。
点「**上传并替换**」就会逐张上传，并把正文里的 `src` 换成微信地址（预览和体检区立刻同步）。

**两条接口，区别要分清：**

| | `media/uploadimg`（默认） | `material/add_material`（勾上「传成永久素材」） |
| -- | -- | -- |
| 进不进素材库 | **不进**，后台素材库里翻不到 | **进**，可在素材库里翻到、可复用 |
| 占不占配额 | **不占**素材库张数配额 | **占** |
| 限制 | 仅 jpg/png，≤1MB | ≤10MB，格式更宽 |

图超过 1MB 或不是 jpg/png 时，会自动回退到永久素材那条路（不用你手动切）。

**传过一次就记住**：上传结果按图片内容记在一张映射表里（localStorage `gzh.imgmap`），
同一张占位图不会重复传，之后每次重渲染都直接套用微信地址。
需要重来就点「**清除映射**」（会连带重新渲染回 base64 占位图）。

---

## 五、两个坑（都会拦住你）

**① 正文里还有 base64 图。**
发送前会数一遍，有的话弹窗让你先去点「上传并替换」（第四节）。
强行发送也能发，但那些图在公众号里显示不出来。

**② 封面是必填的。**
草稿接口的 `thumb_media_id` 没有「留空」这个选项，没填会直接被拦下。

---

## 六、密钥安全

- 存在 `localStorage`（key `gzh.publish`），**明文**。file:// 下实测可写。
- **不写进导出主题**：导出的 `.js` 里只有主题数据，没有密钥。
- 面板底部有「**清除密钥**」，一键抹掉 AppID / AppSecret（代理地址、封面 media_id 等配置保留）。
- 共用电脑 / 开了浏览器同步的话，发完稿建议点一次清除。

---

## 七、验收测试

```bash
node check/smoke_publish.js      # 发布面板 · 12 项
node check/smoke_imgupload.js    # 正文图片上传 · 17 项
```

前者含最关键的这条：**file:// 页面能不能 fetch 本机代理**（CORS 通不通）。
后者验证 multipart 上传能穿过代理到微信（用假 token 触发 `40001` 证明请求真的送达），
以及「传过一次就记住」的映射在重新渲染后真的套用上了。
这两条只能靠真实浏览器验证，改代理或改页面后请重跑。
